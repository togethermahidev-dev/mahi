# Mahi

Mahi is a show-up fitness accountability app. The iPhone app is in `ui/`, the waitlist website in
`web/`, the database in `supabase/`, the staff portal in `staff/`.

## Deploy the website

Netlify only builds the website when this file (or `web/DEPLOY.md`) changes. Every other push is
skipped.

To deploy: on GitHub, signed in as **togethermahidev-dev**, edit this file, change the date below,
and commit it to `main`. It's live a minute or two later (check **Deploys** in Netlify).
